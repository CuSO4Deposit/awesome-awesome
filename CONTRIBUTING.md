# Contributing

Thanks for wanting to add something. This list is deliberately small, so the bar is high.

## The bar an entry has to clear

A list gets included only if all of these are true:

1. **It is a curated list**, not a single project, a blog post, or a product page.
2. **It is actively maintained.** The last meaningful update is recent, and there is a human behind it.
3. **It is genuinely useful.** It is well-organized, the links work, and it is not padded with filler.
4. **It is not spam or an ad.** No affiliate links, no self-promotion of a paid product, no SEO scrape.
5. **It fits an existing section**, or it is strong enough to justify a new one.

When in doubt, we leave it out. A short list of good links beats a long list of mediocre ones.

## How to suggest an entry

1. Open an issue or pull request.
2. For a pull request, add the entry to the correct section in `README.md` using this format:

   ```
   - [Name](https://github.com/owner/repo) — One sentence on what it covers. — *One sentence on why it is worth keeping.*
   ```

3. Keep the description factual and the note specific. Avoid marketing language.
4. One entry per pull request keeps review easy.

## Removing entries

An entry is removed when it goes unmaintained, fills up with spam, or gets superseded by a clearly better list. Removing is not a judgment on the past — lists rot over time.
