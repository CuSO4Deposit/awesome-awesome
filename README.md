## Self-Hosted & Privacy

- [awesome-selfhosted](https://github.com/awesome-selfhosted/awesome-selfhosted) — Free software network services you can host yourself. — _The definitive list of self-hostable services._
- [awesome-sysadmin](https://github.com/awesome-foss/awesome-sysadmin) — System administration resources. — _A broad sysadmin toolbox._
- [awesome-docker](https://github.com/veggiemonk/awesome-docker) — Docker resources and tooling. — _References and tools in one place._
- [awesome-privacy](https://github.com/Lissy93/awesome-privacy) — Privacy-respecting software and services. — _Well-maintained alternative to the usual privacy link dumps._

## Quantified Self & Personal Data

- [awesome-quantified-self](https://github.com/woop/awesome-quantified-self) — Devices, apps, and tools for self-tracking. — _The most complete single QS index._
- [awesome-quantified-self (markwk)](https://github.com/markwk/awesome-quantified-self) — Self-tracking tools, apps, and wearables. — _Broader coverage of the analytics and wearable side._
- [Personal-Analytics-Resources](https://github.com/vijayvardhan94/Personal-Analytics-Resources) — Personal analytics and lifelogging resources. — _Narrower and older, but strong on lifelogging and personal big data._

## Tools & Productivity

- [awesome-cli-apps](https://github.com/agarrharr/awesome-cli-apps) — Command-line apps for every task. — _Best single place to find a CLI tool for a given job._
- [terminals-are-sexy](https://github.com/k4m4/terminals-are-sexy) — Terminal frameworks, plugins, and themes. — _The place to steal dotfiles and shell upgrades from._
- [awesome-shell](https://github.com/alebcay/awesome-shell) — Shell frameworks, toolkits, and guides. — _Language-agnostic shell tooling._
- [awesome-macos-command-line](https://github.com/herrbischoff/awesome-macos-command-line) — Control macOS entirely from the command line. — _Turns macOS into scriptable muscle memory._
- [awesome-mac](https://github.com/jaywcjlove/awesome-mac) — macOS apps and tools. — _The macOS app list that isn't pure spam._
- [awesome-productivity](https://github.com/jyguyomarch/awesome-productivity) — Productivity tools and practices. — _Mixes process with tooling, so it's more than a link dump._
- [the-book-of-secret-knowledge](https://github.com/trimstray/the-book-of-secret-knowledge) — Sysadmin and security one-liners, tools, and references. — _Dense and practical; a shelf of hard-won knowledge._

## Development

- [awesome-python](https://github.com/vinta/awesome-python) — Python frameworks, libraries, software, and tools. — _The list to check before reaching for a new Python library._
- [awesome-go](https://github.com/avelino/awesome-go) — Go frameworks, libraries, and software. — _Same role for Go; stays current and well-tended._
- [awesome-rust](https://github.com/rust-unofficial/awesome-rust) — Rust code and resources. — _Deep, actively maintained, and a good map of the crate ecosystem._
- [awesome-java](https://github.com/akullpp/awesome-java) — Java frameworks, libraries, and software. — _The standard starting point for the JVM._
- [awesome-cpp](https://github.com/fffaraz/awesome-cpp) — C/C++ frameworks, libraries, and resources. — _The best single index for C/C++ libraries and tooling._
- [awesome-nodejs](https://github.com/sindresorhus/awesome-nodejs) — Node.js packages and resources. — _Curated tightly enough to actually be usable._
- [awesome-react](https://github.com/enaqx/awesome-react) — The React ecosystem. — _Covers the whole ecosystem, not just component libraries._
- [awesome-vue](https://github.com/vuejs/awesome-vue) — Vue.js ecosystem resources. — _Broad, community-maintained, and stays in sync with Vue releases._
- [awesome-tailwindcss](https://github.com/aniftyco/awesome-tailwindcss) — Tailwind CSS resources and plugins. — _Small but tight; jump-starts real Tailwind work._

## Artificial Intelligence & Data

- [awesome-machine-learning](https://github.com/josephmisiti/awesome-machine-learning) — ML frameworks and libraries, organized by language. — _The broadest single ML index._
- [awesome-deep-learning](https://github.com/ChristosChristofidis/awesome-deep-learning) — Deep learning tutorials, projects, and communities. — _Good for building a learning path, not just a toolchain._
- [awesome-nlp](https://github.com/keon/awesome-nlp) — Natural language processing resources. — _Well-organized tooling and papers for NLP._
- [Awesome-LLM](https://github.com/Hannibal046/Awesome-LLM) — Papers, models, and frameworks for large language models. — _One of the best LLM trackers right now._
- [awesome-generative-ai](https://github.com/steven2358/awesome-generative-ai) — Generative AI projects and services. — _Practical, and updated frequently in a fast-moving space._
- [awesome-ai-agents](https://github.com/e2b-dev/awesome-ai-agents) — Agent frameworks and real projects. — _Rare focused index of the agent ecosystem._
- [awesome-datascience](https://github.com/academic/awesome-datascience) — Data science curriculum, tools, and datasets. — _A broad map of the field beyond just libraries._
- [awesome-computer-vision](https://github.com/jbhuang0604/awesome-computer-vision) — Computer vision papers and code. — _Solid CV resource that pairs papers with implementations._
- [awesome-mlops](https://github.com/visenger/awesome-mlops) — MLOps tools and practices. — _The operational side of ML, which most lists ignore._
- [best-of-ml-python](https://github.com/ml-tooling/best-of-ml-python) — Ranked, continuously updated ML libraries for Python. — _Ranks and filters, which cuts through library noise._
